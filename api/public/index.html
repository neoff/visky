Install it

Point a camera at the code. iOS is on the App Store; Android installs from here while the Play listing is still in review.

iPhone, iPad & Mac

One build for iOS, iPadOS and Apple silicon Macs. CarPlay and an Apple Watch app are included.

App Store Opens apps.apple.com

Android

The signed APK, straight from the project's GitHub release. Android asks once for permission to install it.

Download APK com.envarg.visky · universal, ~130 MB

Android, via Google Play

The Play listing is in closed testing. Join the test and the app updates itself from Play like any other.

Join the test Needs an invited Google account

Desktop

A 16 MB native shell for macOS — the same player, the same hand-over, on a window you can leave open all day.

Mac App Store Universal, Apple silicon and Intel
